# قفل اللمس (Touch Lock)

تطبيق بسيط بيقفل شاشة اللمس بالكامل مع سيبان الأزرار الفيزيائية شغالة عادي.

## إزاي بيشتغل
- التطبيق بيحط طبقة شفافة (Overlay) فوق الشاشة كلها بتاخد أي لمسة وتوقفها.
- الأزرار (D-Pad / الكيباد) بتفضل شغالة عادي لأن الطبقة دي معمولة عشان توقف اللمس بس.

## طريقة البناء (بدون كمبيوتر) عن طريق GitHub

1. اعمل حساب على github.com لو مش عندك.
2. اعمل Repository جديد (اسمه مثلاً TouchLockApp)، خليه Public.
3. ارفع كل الملفات والمجلدات اللي في المشروع ده (فيه ملف .github/workflows/build.yml جاهز).
4. روح لتبويب **Actions** في الريبو، هتلاقي الـ Workflow اشتغل تلقائي.
5. لما يخلص (لونه أخضر ✅)، ادخل عليه، وهتلاقي تحت **Artifacts** ملف اسمه `TouchLockApp-debug` — نزّله، هيكون ملف zip فيه الـ APK جواه.
6. فك الضغط، هتلاقي `app-debug.apk` — انقله لتليفونك ونزّله (لازم تفعّل "مصادر غير معروفة" في إعدادات الجهاز الأول).

## طريقة الاستخدام على التليفون

1. افتح تطبيق "قفل اللمس".
2. اضغط **"1) طلب إذن العرض فوق التطبيقات"** ووافق من الشاشة اللي هتظهر.
3. ارجع للتطبيق واضغط **"2) تفعيل قفل اللمس"** — اللمس هيتوقف فورًا في كل الشاشة.
4. عشان توقفه تاني: استخدم الأزرار (D-Pad) بس عشان توصل لأيقونة التطبيق من الشاشة الرئيسية، افتحه، وانزل بالسهم لزرار **"إيقاف قفل اللمس"** واضغط OK.

## تحذير مهم
- ده كود مبدئي (Debug build) لتجربة شخصية على جهازك، مش موقّع (signed) بشكل نهائي للنشر.
- لو الجهاز رفض تفعيل "مصادر غير معروفة" من الأساس، يبقى النظام (digiOS) مقفول من الشركة المصنّعة ومينفعش تركيب تطبيقات خارجية عليه خالص.
